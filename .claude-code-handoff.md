### Step 2: Fix any type/content mismatches

The `SceneRenderer` switch in `DynamicAnimation.tsx` (lines 3225–3322) maps these scene types:
- `title` → `TitleScene` (content: `title`, `subtitle`, `color`, `backgroundColor`)
- `steps` / `features` → `StepsScene` (content: `title`, `items: [{icon, label, description, value}]`)
- `text` → `TextScene`
- `stats` → `StatsScene` (content: `stats: [{value, label, numericValue, prefix, suffix}]`)
- `chart` → `ChartScene`
- `media`, `comparison`, `countdown`, `shapes`, `emoji`, `gif`, `lottie`, `3d`

Our converter outputs `type: "features"` for agent cards and `type: "steps"` for individual workflow steps. These are correct. The issue is that each individual step generates a separate scene — for workflows with many steps, this creates many sequential scenes, which is fine.

## Remotion CLI

Located in the project at `labs/hyperedit/`. Use `npx remotion render`.
The composition is `DynamicAnimation` in `src/remotion/index.tsx`.
The props JSON format is:
```json
{
  "scenes": [{ "id": "...", "type": "...", "duration": <frames>, "content": {...}, "transition": {...} }],
  "backgroundColor": "#0a0a0f",
  "totalDuration": 3870
}
```

## Potential Issues to Watch For

1. **Color format**: Director output uses `#00D4FF` with `#` prefix. Remotion components may or may not strip `#` automatically. If you see color errors, strip the `#`.
2. **Description text**: Some descriptions start with `: ` (e.g., `: Identify escalation condition`). The parser includes a colon artifact from the markdown step format. Clean this up if it looks bad in the render.
3. **First agent card**: The first agent parsed is empty (`{ "name": "Agent" }`) — this was a parser issue with a missing `#` heading. The converter handles it gracefully but it's an empty card.
4. **Scene count**: 24 scenes is a lot. If rendering takes too long, use `--frames=0-900` to render just the first 30 seconds as a preview.

## Success Criteria

- MP4 at `spec-kit-video-output/output.mp4` with valid video content
- At least the title card, one agent card, and one step should be visible
- 1920x1080, 30fps, ~129 seconds
